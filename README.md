# Level C 配音闯关

一个给儿童使用的英文分级阅读配音闯关网页。内容包含原创 Level C 风格英文课文、中文翻译、重点词汇、音标讲解、录音自动评分和学习效果测试。

## 使用方式

请通过本地服务器打开，避免浏览器在 `file://` 页面下限制麦克风录音。

```bash
npm start
```

然后打开：

```text
http://localhost:3000
```

- 全部 30 个 Unit 默认免费开放。
- 全站共 30 个 Unit，每个 Unit 有 8 个 Level。
- 每个 Level 使用 6 句短文，对标小学英语三四年级的阅读练习。
- 点击“听一遍”播放浏览器英文朗读。
- 中文翻译逐句放在英文句子下方；朗读时当前英文单词和对应中文句子会同步高亮。
- 词汇板块增加句型讲解和语法讲解。
- 点击“开始录音”后朗读当前 Level，再点击“停止录音”。
- 停止录音后系统自动评分，不需要提交按钮。
- 3 星通过当前 Level，并自动解锁下一 Level。
- 录音区在测试题上方；每个 Level 有 6 道小测试，覆盖词汇、音标、句型、语法和阅读理解，答对/答错会播放不同音效。

## 内容说明

网页中的课文均为原创 Level C 风格文本，不复制 RAZ 或其他受版权保护的分级读物原文。后续如接入已授权课文，可替换 `app.js` 中的课程数据。

## 评分说明

评分在本地浏览器完成，不上传录音。当前版本根据录音时长、声音清晰度，以及浏览器支持时的英文语音识别匹配度给出 1-3 星。

## GitHub Pages 发布

项目是纯静态页面，发布根目录即可：

1. 推送到 GitHub 仓库。
2. 在仓库 Settings -> Pages 中选择 `main` 分支和根目录。
3. 等待 GitHub Pages 生成公开访问地址。
