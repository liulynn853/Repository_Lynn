# Level C 配音闯关

一个给儿童使用的英文分级阅读配音闯关网页。内容包含原创 Level C 风格英文课文、中文翻译、重点词汇、音标讲解、录音自动评分和 30 RMB 后续单元付费解锁。

## 使用方式

请通过本地服务器打开，避免浏览器在 `file://` 页面下限制麦克风录音。

```bash
npm start
```

然后打开：

```text
http://localhost:3000
```

- 默认免费使用 Unit 1-20。
- 输入 30 RMB 付费激活码后，可解锁 Unit 21-30。
- 全站共 30 个 Unit，每个 Unit 有 8 个 Level。
- 每个 Level 使用 6 句短文，对标小学英语三四年级的阅读练习。
- 点击“听一遍”播放浏览器英文朗读。
- 中文翻译逐句放在英文句子下方；朗读时当前英文单词和对应中文句子会同步高亮。
- 点击“开始录音”后朗读当前 Level，再点击“停止录音”。
- 停止录音后系统自动评分，不需要提交按钮。
- 3 星通过当前 Level，并自动解锁下一 Level。
- 录音区在测试题上方；每个 Level 有 4 道小测试，答对/答错会播放不同音效。

## 内容说明

网页中的课文均为原创 Level C 风格文本，不复制 RAZ 或其他受版权保护的分级读物原文。后续如接入已授权课文，可替换 `app.js` 中的课程数据。

## 评分说明

评分在本地浏览器完成，不上传录音。当前版本根据录音时长、声音清晰度，以及浏览器支持时的英文语音识别匹配度给出 1-3 星。

## 付费激活码

静态 MVP 使用人工付款 + 激活码模式。Unit 1 默认免费，后续单元通过激活码解锁：

- `RAZC-30-ALL`
- `KIDS-VOICE-30`

这类静态激活码适合产品验证，不能防止专业绕过。正式商业化建议升级为后端账号、订单、支付回调和服务端鉴权。

## GitHub Pages 发布

项目是纯静态页面，发布根目录即可：

1. 推送到 GitHub 仓库。
2. 在仓库 Settings -> Pages 中选择 `main` 分支和根目录。
3. 等待 GitHub Pages 生成公开访问地址。
